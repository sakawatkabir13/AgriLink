# Contributing to AgriLink 🌾

Thanks for your interest in improving **AgriLink**! We welcome issues, ideas, and pull requests.

Please read the [Contributing section in the README](./README.md#-contributing) for the full workflow, code-style expectations, and how to run the project locally.

## Quick links
- 🐛 [Report a bug](https://github.com/sakawatkabir13/AgriLink/issues)
- ✨ [Request a feature](https://github.com/sakawatkabir13/AgriLink/issues)
- 🔒 [Security advisories](#security)

## Local setup
```bash
npm install
cp .env.example .env  # then fill in your Supabase keys
npm run dev
```

## Before opening a PR
```bash
npm run lint
npm run test
npm run build
```

## Security
Please **do not** open public issues for security vulnerabilities. Contact the maintainer through GitHub directly so it can be handled responsibly.
